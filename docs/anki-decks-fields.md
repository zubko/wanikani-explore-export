# Anki Deck Fields

Each deck has a set of fields that make up a note. Fields are grouped by which side of the card they appear on: **Front** (the prompt shown during review) and **Back** (the answer revealed after flipping).

## Japanese Radicals

**Front:**
character

**Back:**

mnemonic_image,
